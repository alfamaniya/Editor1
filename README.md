**قاعده اجرا:** در هر نوبت روی مرحله جاری تمرکز می‌کنیم؛ ابتدا مسئولیت و رفتار آن مشخص می‌شود، سپس کد پیاده‌سازی و آزمایش می‌شود. وضعیت جدول و READMEها با پیشرفت واقعی پروژه به‌روزرسانی خواهند شد. افزودن قابلیت یا تغییر ترتیب مراحل بدون هماهنگی با مدیر پروژه انجام نمی‌شود.

## قوانین اصلی پروژه

1. فایل‌های ریشه شامل `index.html`، `style.css` و `script.js` هسته مرکزی پروژه هستند.
2. هر بخش مستقل باید پوشه اختصاصی با نام مرتبط در مسیر `core/` داشته باشد.
3. هر بخش باید دقیقاً سه فایل اصلی داشته باشد: HTML، CSS و JavaScript.
4. کدهای اختصاصی هر بخش باید فقط در پوشه همان بخش قرار بگیرند.
5. فایل‌های ریشه مسئول چیدمان کلی و اتصال بخش‌ها هستند؛ منطق اختصاصی بخش‌ها نباید به فایل‌های ریشه منتقل شود.
6. زبان README فارسی است؛ اما تمام متن‌های رابط کاربری، نام‌گذاری‌ها، شناسه‌ها و توضیحات داخل کد باید انگلیسی باشند.
7. در هر تغییر ساختاری یا عملکردی، این فایل و README اختصاصی AlfaCode باید متناسب با وضعیت واقعی پروژه به‌روزرسانی شوند.
8. ساختار بخش‌ها باید مستقل و قابل توسعه باقی بماند.
9. قابلیت جدید فقط با درخواست صریح مدیر پروژه پیاده‌سازی می‌شود.

## معرفی پروژه

Editor1 یک پروژه ماژولار برای توسعه محیط ویرایش کد است. در ساختار فعلی، صفحه اصلی شامل دو بخش ظاهری Editor و Live Preview است.

پوشه `alfacode/` محل توسعه موتور ویرایشگر کد اختصاصی AlfaCode است؛ موتوری مستقل و ماژولار با الهام از معماری و قابلیت‌های ویرایشگرهایی مانند Monaco و CodeMirror.

نسخه اولیه AlfaCode برای شناخت و پشتیبانی از HTML، CSS و JavaScript طراحی می‌شود. معماری باید امکان افزودن زبان‌های دیگر را بدون بازنویسی هسته فراهم کند. توسعه با اولویت اجرای محلی و آفلاین انجام خواهد شد.

## مسئولیت بخش‌های اصلی AlfaCode

- `src/core/`: مدیریت وضعیت ویرایشگر، سند، انتخاب متن، تراکنش‌ها و تاریخچه.
- `src/rendering/`: نمایش محیط ویرایش، خطوط و مکان‌نما.
- `src/input/`: دریافت ورودی صفحه‌کلید و مدیریت کلیپ‌بورد.
- `src/language/`: مدیریت زبان‌ها، توکن‌سازی و هماهنگی تحلیلگرها.
- `src/language/html/`: قواعد و تحلیل ساختار HTML.
- `src/language/css/`: قواعد و تحلیل ساختار CSS.
- `src/language/javascript/`: قواعد و تحلیل ساختار JavaScript.
- `src/features/`: امکانات مستقل مانند شماره خطوط، رنگ‌بندی نحوی و تطبیق پرانتزها.
- `src/themes/`: مدیریت تم‌های روشن و تاریک.
- `src/utils/`: ابزارهای عمومی مشترک.
- `tests/`: محل آزمون‌های خودکار.
- `examples/`: نمونه‌های استفاده از موتور.

## وضعیت پیاده‌سازی

در این مرحله فقط اسکلت پوشه‌ها و فایل‌های پایه AlfaCode ایجاد شده است. فایل‌های منبع خالی هستند و هنوز موتور ویرایش، تحلیل زبان، رنگ‌بندی یا قابلیت اجرایی دیگری پیاده‌سازی نشده است.

## اجرای پروژه

برای مشاهده پوسته فعلی Editor1، فایل `index.html` را در مرورگر باز کنید. موتور AlfaCode هنوز به بخش Editor متصل نشده است.
