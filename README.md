# Editor1

ویرایشگر وب HTML، CSS و JavaScript با پیش‌نمایش زنده و نسخه مستقل آفلاین.

## وضعیت
- مقایسه اولیه سازگاری کاتالوگ JSON با موتور HTML انجام شد؛ داده JSON گسترده‌تر است و اتصال باید context/parentTags و fallback رتبه‌بندی را حفظ کند.
- طرح adapter برای تبدیل JSON HTML به گزینه‌های داخلی موتور و حفظ context، parent-child، رتبه‌بندی و قرارداد UI ثبت شد؛ اجرا هنوز انجام نشده است.
- طرح آزمون Shadow برای HTML ثبت شد: legacy و adapter JSON روی fixtureهای root/body/head/p/list/table/select/SVG و opening/closing/chain/void/raw-text مقایسه شوند؛ runtime هنوز legacy است.
- ممیزی ریسک اتصال HTML فهرست شد: close/jump-close، chain، head/root، SVG، phrasing، parentTags، ranking و قرارداد درج باید در adapter و Regression حفظ شوند.
- محیط ویرایش، تب‌های سه زبان، Preview، ذخیره محلی و رابط موبایل پیاده‌سازی شده‌اند.
- صفحه «فهرست تکمیل خودکار» هر سه JSON را در جدول تمام‌فیلدی شبیه اکسل نمایش می‌دهد؛ جستجو در تمام فیلدها، مرتب‌سازی با کلیک روی سرستون، اسکرول افقی و نمایش مقادیر آرایه/شیء پشتیبانی می‌شود. دکمه بازگشت فقط تلاش می‌کند پنجره را ببندد. اتصال پیشنهادهای runtime به JSONها هنوز باقی است.
- عنوان ۸ نقشه در مرکز نقشه‌ها به فارسی ساده و کوتاه تغییر داده شد.
- نسخه آفلاین ساخته می‌شود؛ آزمون مرورگر و قطع اینترنت هنوز کامل نیست.

## اولویت باقی‌مانده
1. اتصال runtime پیشنهادهای داخل ویرایشگر به JSONها (context، درج و تست)؛ بررسی اولیه موتور HTML، ساختار JSON، Loader مشترک و مسیر اتصال HTML به Editor انجام شد؛ یافته‌ها در نقشه جامع ثبت شده‌اند.
2. تکمیل Context/Snippet و اتصال کاتالوگ‌های زبان.
3. مدیریت ورود، اعتبارسنجی و انتشار امن داده.
4. آزمون کامل offline روی مرورگر/موبایل، به‌ویژه CSS/JS و اجزای باقی‌مانده.
5. Ranking، کارایی و ممیزی نهایی.

جزئیات و کارهای باقی‌مانده در [نقشه جامع کارهای باقی‌مانده](./maps/remaining-work.md) و [مرکز نقشه‌ها](./maps/map.html).

## ساختار
- `core/`: اجزای رابط
- `alfacode/`: موتور و کاتالوگ
- `scripts/`: ابزار ساخت
- `offline/`: خروجی

## اجرا
از ریشه مخزن اجرا کنید:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید. به‌دلیل JavaScript modules، اجرای مستقیم `file://` مناسب توسعه نیست.

## خروجی آفلاین
از `scripts/build-offline.mjs` و `scripts/offline-manifest.json` ساخته می‌شود. پس از تغییر سورس، build را مجدداً اجرا کنید؛ خروجی را دستی ویرایش نکنید.

## آزمون
نتایج CI و آزمون دستی جدا ثبت شوند؛ Build موفق جایگزین تست مرورگر نیست.
