# Editor1

ویرایشگر وب HTML، CSS و JavaScript با پیش‌نمایش زنده و نسخه مستقل آفلاین.

## وضعیت
- کاتالوگ‌های JSON هر سه زبان به موتور زنده پیشنهادهای HTML، CSS و JavaScript متصل شدند؛ Loader مشترک هنگام راه‌اندازی Editor هر سه فایل را بارگذاری می‌کند.
- موتور HTML با حفظ پیشنهادهای Legacy از JSON برای گسترش تگ‌ها و SVG استفاده می‌کند؛ CSS از JSON برای property، selector، value، at-rule، function و unit و JavaScript برای identifier و member استفاده می‌کند.
- تست Shadow HTML با ۳۲ fixture حفظ شده است؛ تست‌های runtime جدید برای اثبات استفاده مستقیم از JSONهای هر سه زبان اضافه شدند. نتیجه CI اتصال جدید باید پس از اجرای GitHub Actions ثبت شود.
- ممیزی ریسک اتصال HTML انجام شد و Adapter آزمایشی برای استخراج stack واقعی از parser، تفکیک parent از context، حفظ گزینه‌های Legacy و ترتیب محلی اصلاح شد. close/jump-close، chain، head/root، SVG، phrasing، parentTags، ranking و قرارداد درج همچنان باید در Regression نهایی حفظ شوند.
- محیط ویرایش، تب‌های سه زبان، Preview، ذخیره محلی و رابط موبایل پیاده‌سازی شده‌اند.
- صفحه «فهرست تکمیل خودکار» هر سه JSON را در جدول تمام‌فیلدی شبیه اکسل نمایش می‌دهد؛ جستجو در تمام فیلدها، مرتب‌سازی با کلیک روی سرستون، اسکرول افقی و نمایش مقادیر آرایه/شیء پشتیبانی می‌شود.
- عنوان ۸ نقشه در مرکز نقشه‌ها به فارسی ساده و کوتاه تغییر داده شد.
- نسخه آفلاین ساخته می‌شود؛ آزمون مرورگر و قطع اینترنت هنوز کامل نیست.

## اولویت باقی‌مانده
1. تکمیل Regression و تأیید رفتار Context/درج پیشنهادهای JSON در مرورگر و نسخه آفلاین.
2. گسترش پشتیبانی Context و Snippetهای فعال‌شونده؛ تکمیل پیشنهادهای CSS/JS برای contextهای تخصصی.
3. مدیریت ورود، اعتبارسنجی و انتشار امن داده.
4. آزمون کامل offline روی مرورگر/موبایل، به‌ویژه CSS/JS و اجزای باقی‌مانده.
5. Ranking، کارایی و ممیزی نهایی.

جزئیات و کارهای باقی‌مانده در [نقشه جامع کارهای باقی‌مانده](./maps/remaining-work.md) و [مرکز نقشه‌ها](./maps/map.html).

## ساختار
- `core/`: اجزای رابط
- `alfacode/`: موتور و کاتالوگ
- `scripts/`: ابزار ساخت
- `offline/`: خروجی

## اجرا
از ریشه مخزن اجرا کنید:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید. به‌دلیل JavaScript modules، اجرای مستقیم `file://` مناسب توسعه نیست.

## خروجی آفلاین
از `scripts/build-offline.mjs` و `scripts/offline-manifest.json` ساخته می‌شود. پس از تغییر سورس، build را مجدداً اجرا کنید؛ خروجی را دستی ویرایش نکنید.

## آزمون
نتایج CI و آزمون دستی جدا ثبت شوند؛ Build موفق جایگزین تست مرورگر نیست.
