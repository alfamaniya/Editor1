# Editor1

ویرایشگر وب HTML، CSS و JavaScript با پیش‌نمایش زنده و نسخه مستقل آفلاین.

## وضعیت
- کاتالوگ‌های JSON هر سه زبان به موتور زنده پیشنهادهای HTML، CSS و JavaScript متصل شدند؛ Loader مشترک هنگام راه‌اندازی Editor هر سه فایل را بارگذاری می‌کند.
- موتور HTML با حفظ پیشنهادهای Legacy از JSON برای گسترش تگ‌ها و SVG استفاده می‌کند؛ CSS از JSON برای property، selector، value، at-rule، function و unit و JavaScript برای identifier و member استفاده می‌کند.
- تشخیص اولیه نوع متغیرهای JavaScript برای پیشنهاد متدهای prototype به موتور افزوده شد؛ شامل سازنده‌ها، literalهای رایج و چند API DOM. متدهای static و instance از هم تفکیک می‌شوند.
- CI نهایی این تغییر: ۹۴ تست موفق، صفر شکست (Run 44493587901). ساخت نسخه آفلاین نیز موفق شد (Run 44493587858).
- ممیزی ساختاری هر سه کاتالوگ انجام شد: شناسه‌ها و فیلدهای پایه بررسی شدند؛ ارجاع‌های CSS به propertyها معتبرند و wildcard عمومی جداگانه کنترل می‌شود؛ owner و memberKindهای JavaScript بررسی شدند. یک نقص واقعی HTML اصلاح شد: والد dl در parentTags به‌کار رفته بود اما رکورد dl وجود نداشت؛ رکورد آن افزوده و آزمون ارجاع والدها اضافه شد. آزمون CI پس از اصلاح: ۹۷ تست موفق و صفر شکست (Run 44494050844)؛ Offline Build نیز موفق (Run 44493977402).
- ممیزی ریسک اتصال HTML انجام شد و Adapter آزمایشی برای استخراج stack واقعی از parser، تفکیک parent از context، حفظ گزینه‌های Legacy و ترتیب محلی اصلاح شد. close/jump-close، chain، head/root، SVG، phrasing، parentTags، ranking و قرارداد درج همچنان باید در Regression نهایی حفظ شوند.
- محیط ویرایش، تب‌های سه زبان، Preview، ذخیره محلی و رابط موبایل پیاده‌سازی شده‌اند.
- صفحه «فهرست تکمیل خودکار» هر سه JSON را در جدول تمام‌فیلدی نمایش می‌دهد؛ جستجو، مرتب‌سازی، اسکرول افقی و نمایش آرایه/شیء دارد. پنل مدیریت پیش‌نویس نیز ورود JSON و CSV/TSV (از جمله Paste مستقیم سلول‌های Excel)، افزودن/ویرایش/حذف رکورد، تشخیص تکرار، اعتبارسنجی، ذخیره محلی و خروجی JSON را فراهم می‌کند. این ابزار فایل اصلی را خودکار تغییر نمی‌دهد و انتشار GitHub در آن فعال نیست.
- عنوان ۸ نقشه در مرکز نقشه‌ها به فارسی ساده و کوتاه تغییر داده شد.
- نسخه آفلاین با داده‌های JSON تعبیه‌شده ساخته می‌شود. CI جدید ۸۰ فایل Runtime را بررسی کرد، صفر وابستگی خارجی یافت و تمام رکوردهای سه کاتالوگ را در خروجی مستقل تأیید کرد؛ حجم خروجی ۱۷۵۵٫۲۳ KiB است. آزمون دستی واقعی مرورگر و قطع اینترنت همچنان باقی است.
- CI کیفیت: ۱۰۵ تست موفق، صفر شکست (Run 44495264591). آزمون latency در محیط GitHub Actions: p95 برای HTML برابر ۰٫۲۸ ms، CSS برابر ۰٫۰۶ ms و JavaScript برابر ۰٫۰۷ ms؛ این اعداد معیار محیط CI هستند، نه تضمین عملکرد دستگاه کاربر.
- Build و ممیزی خروجی آفلاین موفق: Run 44495264825؛ ممیزی خروجی تمام رکوردهای HTML/CSS/JavaScript و نبود منابع خارجی را تأیید کرد.

## اولویت باقی‌مانده
1. آزمون دستی Context، درج، Cursor و پیشنهادهای هر سه زبان در مرورگر؛ سپس آزمون آفلاین بدون اینترنت.
2. تکمیل contextهای تخصصی و طراحی مسیر فعال‌سازی امن Snippetهای JavaScript (فعلاً غیرفعال‌اند).
3. تکمیل مدیریت کاتالوگ: ورود مستقیم فایل XLSX، نگاشت ستون‌ها و انتشار امن GitHub با کنترل SHA/Conflict.
4. آزمون دستی Offline روی مرورگر دسکتاپ و موبایل، به‌ویژه قطع واقعی اینترنت و Preview CSS/JS.
5. Regression نهایی UI، اندازه‌گیری روی دستگاه واقعی و ممیزی محتوایی استانداردها.

جزئیات و کارهای باقی‌مانده در [نقشه جامع کارهای باقی‌مانده](./maps/remaining-work.md) و [مرکز نقشه‌ها](./maps/map.html).

## ساختار
- `core/`: اجزای رابط
- `alfacode/`: موتور و کاتالوگ
- `scripts/`: ابزار ساخت
- `offline/`: خروجی

## اجرا
از ریشه مخزن اجرا کنید:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید. به‌دلیل JavaScript modules، اجرای مستقیم `file://` مناسب توسعه نیست.

## خروجی آفلاین
از `scripts/build-offline.mjs` و `scripts/offline-manifest.json` ساخته می‌شود. پس از تغییر سورس، build را مجدداً اجرا کنید؛ خروجی را دستی ویرایش نکنید.

## آزمون
نتایج CI و آزمون دستی جدا ثبت شوند؛ Build موفق جایگزین تست مرورگر نیست.
