# قوانین و ساختار پروژه Editor1

## قوانین اصلی پروژه

1. فایل‌های ریشه شامل `index.html`، `style.css` و `script.js` هسته مرکزی پروژه هستند.
2. هر بخش مستقل باید پوشه اختصاصی با نام مرتبط در مسیر `core/` داشته باشد.
3. هر بخش باید دقیقاً سه فایل اصلی داشته باشد: HTML، CSS و JavaScript.
4. کدهای اختصاصی هر بخش باید فقط در پوشه همان بخش قرار بگیرند.
5. فایل‌های ریشه مسئول چیدمان کلی و اتصال بخش‌ها هستند؛ منطق اختصاصی بخش‌ها نباید به فایل‌های ریشه منتقل شود.
6. زبان README فارسی است؛ اما تمام متن‌های رابط کاربری، نام‌گذاری‌ها، شناسه‌ها و توضیحات داخل کد باید انگلیسی باشند.
7. در هر تغییر ساختاری یا عملکردی، این فایل باید متناسب با وضعیت واقعی پروژه به‌روزرسانی شود.
8. ساختار بخش‌ها باید مستقل و قابل توسعه باقی بماند.
9. تا زمانی که قابلیت جدیدی صریحاً درخواست نشده است، بخش‌ها فقط شامل ساختار و ظاهر باشند و قابلیت اجرایی جدیدی به آن‌ها اضافه نشود.

## معرفی پروژه

Editor1 یک پروژه ماژولار برای توسعه یک محیط ویرایش کد است. در ساختار فعلی، صفحه اصلی از دو بخش ظاهری تشکیل شده است: ویرایشگر در سمت چپ و پیش‌نمایش زنده در سمت راست.

در وضعیت فعلی هیچ قابلیت ویرایش کد، اجرای کد یا همگام‌سازی زنده پیاده‌سازی نشده است. این دو بخش فعلاً فقط پوسته و ظاهر اولیه هستند.

## ساختار پوشه‌ها و فایل‌ها

```text
Editor1/
├── index.html
├── style.css
├── script.js
├── README.md
└── core/
    ├── editor/
    │   ├── editor.html
    │   ├── editor.css
    │   └── editor.js
    └── preview/
        ├── preview.html
        ├── preview.css
        └── preview.js
```

## مسئولیت فایل‌ها

### فایل‌های مرکزی

- `index.html`: ساختار صفحه اصلی و محل قرارگیری دو بخش.
- `style.css`: استایل و چیدمان کلی صفحه اصلی.
- `script.js`: هماهنگ‌کننده مرکزی؛ در حال حاضر قابلیت اجرایی ندارد.

### بخش Editor

- `core/editor/editor.html`: ساختار ظاهری بخش Editor.
- `core/editor/editor.css`: استایل اختصاصی بخش Editor.
- `core/editor/editor.js`: محل کدهای آینده بخش Editor؛ فعلاً بدون قابلیت اجرایی.

### بخش Preview

- `core/preview/preview.html`: ساختار ظاهری بخش Live Preview.
- `core/preview/preview.css`: استایل اختصاصی بخش Preview.
- `core/preview/preview.js`: محل کدهای آینده بخش Preview؛ فعلاً بدون قابلیت اجرایی.

## اجرای پروژه

برای مشاهده ظاهر اولیه، فایل `index.html` را در مرورگر باز کنید.
