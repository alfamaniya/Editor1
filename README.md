# Editor1

ویرایشگر ساده HTML، CSS و JavaScript.

## ساختار پروژه

- `index.html` — ساختار رابط کاربری ویرایشگر
- `style.css` — استایل و چیدمان رابط کاربری
- `script.js` — منطق اجرای کد و نمایش پیش‌نمایش

## اجرا

فایل `index.html` را در مرورگر باز کنید. کدهای HTML، CSS و JavaScript را در بخش‌های مربوط وارد کنید و با انتخاب «اجرای کد» خروجی را در پنل پیش‌نمایش ببینید.
