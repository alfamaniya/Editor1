# مدیریت و انتشار کاتالوگ

هدف: ورود، اعتبارسنجی، ویرایش و انتشار امن رکوردها.

**وضعیت: ابزار پیش‌نویس محلی پیاده‌سازی و در CI آزمون شده؛ انتشار GitHub و XLSX مستقیم هنوز انجام نشده است.**

## انجام‌شده
- پنل مدیریت در صفحه فهرست تکمیل خودکار اضافه شد.
- ایجاد رکورد اولیه و انتخاب زبان HTML/CSS/JavaScript.
- ورود JSON و CSV/TSV؛ داده‌های کپی‌شده از Excel با Paste قابل ورودند.
- انتخاب، ویرایش JSON و حذف رکورد در پیش‌نویس.
- تشخیص شناسه/کلید معنایی تکراری و اعتبارسنجی فیلدهای عمومی و اختصاصی زبان.
- ذخیره/بازیابی پیش‌نویس در localStorage؛ داده اصلی مخزن تغییر نمی‌کند.
- خروجی JSON نسخه‌دار پس از اعتبارسنجی.
- کنترل ارجاع‌های بین‌رکوردی والدهای HTML و propertyهای CSS.
- آزمون واحد این مسیر در CI: ۱۰۶ تست کلی موفق، صفر شکست (Run 44495592185).

## باقی‌مانده
- ورود فایل XLSX و نگاشت ستون‌ها.
- Validator کامل با تمام قواعد بین‌رکوردی و همسان‌سازی کامل با schema اصلی.
- انتشار امن GitHub: حداقل مجوز، تأیید کاربر، SHA، شاخه، Conflict و آزمون محیط آزمایشی.
- آزمون دستی رابط در دسکتاپ و موبایل.

## امنیت انتشار
ابزار فعلی هیچ GitHub token یا secret را در مرورگر دریافت یا ذخیره نمی‌کند. تا زمان طراحی سرویس سمت سرور یا مسیر انتشار امن دیگر، خروجی JSON برای بازبینی و ثبت کنترل‌شده توسط maintainer است.
