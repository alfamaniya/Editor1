# مدیریت و انتشار کاتالوگ

هدف: ورود، اعتبارسنجی، ویرایش و انتشار امن رکوردها. اتصال runtime در نقشه‌های تکمیل کاتالوگ و New page است؛ این نقشه فقط مدیریت داده را پوشش می‌دهد.

**وضعیت:** طرح اولیه مشخص؛ ابزار مدیریت و انتشار پیاده‌سازی نشده.

## باقی‌مانده — اولویت
**P1 ورودی:** فرم رکورد تکی؛ ورود Excel و نگاشت ستون‌ها؛ Copy/Paste گروهی؛ جدول پیش‌نویس با ویرایش، حذف و تشخیص تکرار.
**P2 اعتبارسنجی:** تولید JSON مطابق schema؛ آزمون داده ناقص/نامعتبر و duplicate.
**P3 انتشار:** اتصال امن GitHub با حداقل مجوز؛ شاخه از آخرین main، کنترل SHA و توقف conflict؛ نمایش نتیجه.
**P4 یکپارچگی:** Validator و Actions؛ بررسی مصرف‌کننده‌ها و جلوگیری از داده موازی؛ پشتیبانی build آفلاین.
**P5 تحویل:** آزمون واحد/یکپارچه/CI، مرورگر آنلاین/آفلاین و مستندات.

معیار: داده ناقص منتشر نشود، conflict امن مدیریت شود و README به‌روز باشد.
