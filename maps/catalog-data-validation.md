# آزمون و اعتبارسنجی داده‌های کاتالوگ

**وضعیت: تکمیل‌شده (اعتبارسنجی اولیه).**

- آزمون JSON، schema/version، فیلدهای مشترک/اختصاصی، زبان و ID.
- کنترل کلیدهای معنایی، ownerهای CSS/JS و snippetهای غیرفعال.
- تطبیق اولیه با موتورهای موجود: HTML ۶۰، CSS ۱۷۴، JavaScript ۱۱۴ رکورد؛ بدون اختلاف گزارش‌شده.
- تست‌های منفی و CI موفق ثبت شده‌اند؛ آزمون‌های گسترش و تفکیک در نقشه‌های مربوط آمده‌اند.

اعتبارسنجی جامع سه فایل پس از اتصال runtime در [نقشه تکمیل کاتالوگ](./catalog-completion.md) انجام می‌شود. این ممیزی جامعیت نسبت به کل استانداردهای روز وب را اثبات نمی‌کند.
