# برنامه ساماندهی READMEها و تفکیک مسیرهای ناتمام

## هدف
بازآرایی مستندات مخزن Editor1 به‌گونه‌ای که README اصلی خلاصه، دقیق و مرجع وضعیت واقعی پروژه باشد؛ README اختصاصی AlfaCode مستند فنی موتور باقی بماند؛ و هر مسیر طراحی‌شده اما ناتمام، برنامه اجرایی مستقل فارسی در شاخه اصلی داشته باشد.

## دامنه
- بازنویسی README اصلی و README اختصاصی AlfaCode با حذف تکرارها، گزارش‌های تاریخی غیرضروری و وضعیت‌های گمراه‌کننده.
- حفظ اطلاعات فنی معتبر، مسیرهای واقعی، لینک‌ها و محدودیت‌های آزموده‌نشده.
- انتقال جزئیات مسیرهای ناتمام از README به فایل‌های برنامه مستقل.
- ایجاد لینک از READMEها به برنامه‌های مستقل.
- عدم تغییر کد اجرایی، تست‌ها، workflowها یا قابلیت‌های محصول.

## یافته‌های اولیه
- README اصلی شامل چندین گزارش توسعه تکراری و دو نقشه مسیر طولانی است.
- README اختصاصی AlfaCode نیز گزارش‌های ممیزی و مرحله‌های داده کاتالوگ را در انتهای مستندات فنی تکرار می‌کند.
- مسیر پیشنهاد تگ HTML هنوز مواردی با وضعیت آزمون مرورگر/IME و تکمیل چرخه تعامل دارد.
- مسیر مدیریت و انتشار کاتالوگ پس از ایجاد JSON اولیه، مراحل اعتبارسنجی و سپس ورود/انتشار/اتصال به موتورها و بسته آفلاین را در پیش دارد.
- برنامه مستقل مرحله ۲-۲ از قبل وجود دارد و باید حفظ و به آن ارجاع داده شود.
