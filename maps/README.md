# مرکز نقشه‌های راه Editor1

این پوشه محل نگهداری نسخه اصلی نقشه‌های راه پروژه است.

## مشاهده نقشه‌ها

فایل [map.html](./map.html) صفحه مرکزی و قابل جست‌وجوی فهرست نقشه‌هاست. دکمه «مپ» در هدر برنامه نیز همین صفحه را باز می‌کند. با انتخاب هر کارت، محتوای فایل Markdown در همان صفحه و داخل سایت نمایش داده می‌شود؛ کاربر به صفحه خام فایل GitHub هدایت نمی‌شود.

## افزودن نقشه جدید

1. فایل نقشه را با نام روشن و یکتا در همین پوشه ایجاد کنید.
2. یک کارت شامل عنوان، توضیح کوتاه و پیوند فایل به بخش `#maps` در `map.html` اضافه کنید.
3. تعداد نقشه‌های ثبت‌شده را در متن شمارنده هماهنگ کنید.
4. فهرست ابتدای README اصلی و در صورت نیاز README همین پوشه را به‌روز کنید.

## قواعد

- نسخه اصلی و جاری هر نقشه فقط در این پوشه نگهداری شود.
- همه فایل‌های نقشه راه فقط در همین پوشه نگهداری می‌شوند؛ در ریشه مخزن و پوشه‌های دیگر نسخه تکراری یا میان‌بُر نقشه نگهداری نمی‌شود.
- وضعیت مراحل، شواهد آزمون و منابع باید در خود نقشه ثبت شوند.
- برای کاتالوگ HTML/CSS/JavaScript، صحت‌سنجی مستند و منابع رسمی شرط پذیرش هر رکورد است.
