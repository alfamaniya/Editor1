# پیشنهاد تگ HTML

**وضعیت:** قابلیت پیاده‌سازی شده؛ ممیزی جامع context و آزمون مرورگر باقی است.

## باقی‌مانده — اولویت
**P1 آزمون رفتار:** ممیزی کد/tests/CI؛ آزمون نمایش، فیلتر، Enter/Tab/Escape/Arrow، درج/Cursor، Undo/Redo، duplicate، موبایل/دسکتاپ و IME فارسی.
**P2 context:** ماتریس contextهای موجود؛ تطبیق با content model WHATWG؛ ثبت نقص و پیشنهاد اصلاح (تغییر موتور نیازمند تأیید).
**P3 اصلاح:** اصلاحات تأییدشده، regression، CI و build آفلاین، آزمون مرورگر و ثبت نتایج.

معیار تکمیل: context و parent/child درست، درج امن، کلیدها و IME آزمایش‌شده و README به‌روز.
