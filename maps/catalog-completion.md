# نقشه راه تکمیل کاتالوگ پیشنهادهای HTML، CSS و JavaScript

## کارهای باقی‌مانده — اولویت‌بندی

> این فهرست، نقطه شروع ادامه کار است. موارد تکمیل‌شده به بخش خلاصه منتقل شده‌اند تا کارهای باز در دسترس و مشخص باشند.

### اولویت ۱ — ضروری: ارزیابی و اتصال کاتالوگ به موتور پیشنهادها
- [ ] **JS-14 — ممیزی اتصال زمان اجرا:** بررسی موتور فعلی پیشنهاد JavaScript، کاتالوگ، AlfaCode و پیشنهادهای فعال؛ شناسایی منطق/داده تکراری و طراحی اتصال بدون تغییر رفتار فعلی.
- [ ] **اعتبارسنجی یکپارچه نهایی کاتالوگ‌ها:** کنترل schema، شناسه‌ها، context، metadata، ترتیب و ارتباط داده‌ها در هر سه فایل؛ رفع موارد ناسازگار و به‌روزرسانی آزمون‌ها.
- [ ] **JS-14.1 — بارگذار کاتالوگ:** طراحی و پیاده‌سازی بارگذاری JSON، مدیریت خطا، cache و جلوگیری از بارگذاری تکراری.
- [ ] **JS-14.2 — اتصال پیشنهادهای JavaScript:** استفاده از کاتالوگ در موتور موجود؛ انتخاب و درج پیشنهاد بدون شکستن رفتار فعلی.

### اولویت ۲ — دقت پیشنهاد و درج
- [ ] **JS-15 — Context Engine:** تشخیص دقیق زمینه تایپ (identifier، بعد از نقطه، رشته، comment، ساختارهای خاص و context نامعتبر).
- [ ] **JS-16 — Snippet Engine:** درج چندخطی کنترل‌شده، جای‌گذاری Cursor/placeholder و جلوگیری از فعال‌شدن ناخواسته snippetها.
- [ ] **JS-17 — اتصال کاتالوگ CSS:** اتصال داده CSS به runtime با تشخیص property/value/selector و context معتبر.
- [ ] **JS-18 — اتصال کاتالوگ HTML:** اتصال داده HTML با رعایت والد/فرزند مجاز، ویژگی‌ها و محل درج.

### اولویت ۳ — کیفیت، سرعت و انتشار
- [ ] **JS-19 — Ranking Engine:** رتبه‌بندی با میزان تطابق، context، ارتباط و اولویت؛ کاهش پیشنهادهای کم‌ربط.
- [ ] **JS-20 — Performance & Cache:** اندازه‌گیری latency، بهینه‌سازی جست‌وجو، بارگذاری و cache.
- [ ] **JS-21 — ممیزی نهایی یکپارچه:** آزمون‌های سه زبان، درج/تبدیل، regression، رفتار مرورگر و نسخه آفلاین؛ ثبت نتایج واقعی.

## خلاصه کارهای انجام‌شده

### HTML — تکمیل شده
- [x] HTML-1 تا HTML-10؛ پوشش عناصر استاندارد متنی، معنایی، رسانه، فهرست، فرم، جدول، تعاملی و SVG؛ ممیزی عناصر منسوخ و آزمایشی.
- [x] **۱۴۶ رکورد**؛ کنترل context، والدهای مجاز، void بودن، namespace، شناسه‌ها و آزمون‌های مربوط.

### CSS — تکمیل شده
- [x] CSS-1 تا CSS-12؛ ویژگی‌ها، انتخابگرها، مقادیر، قواعد at-rule، توابع و واحدها.
- [x] **۹۲۹ رکورد:** ۱۷۹ property، ۶۴ selector، ۵۸۷ value، ۱۵ at-rule، ۵۱ function و ۳۳ unit.
- [x] برای تمام ۱۷۹ ویژگی، دست‌کم یک value وابسته ثبت شد؛ توضیحات و contextها بازبینی شدند.

### JavaScript — تکمیل کاتالوگ داده
- [x] JS-1 تا JS-13؛ کلیدواژه‌ها، globalها، اعضای Object/Array/String/Number/Date/RegExp، Math/JSON/Collections/Promise، DOM، Browser API، Network API، Module/Class و snippetها.
- [x] **۹۰۸ رکورد:** ۱۱۱ identifier، ۷۵۰ member، ۴۴ snippet و ۳ literal.
- [x] metadata محیط اجرا، شناسه‌ها، ترتیب، توضیحات و یکتایی ممیزی شدند؛ snippetها غیرفعال هستند.

## قواعد مرجع برای مراحل بعد
- مستندات معتبر و وضعیت استاندارد قابلیت مبنای ثبت باشد.
- رکورد دارای شناسه پایدار و یکتا، نوع، دسته، عنوان، توضیح و context معتبر باشد.
- پیشنهادهای مرورگر از زبان JavaScript تفکیک شوند.
- موارد deprecated/experimental یا کم‌پشتیبانی در پیشنهادهای عادی قرار نگیرند.
- ترتیب بر اساس ارتباط و context باشد، نه الفبا.
- متن درج‌شونده از عنوان نمایشی جدا باشد و درج، Cursor و کد اطراف را ناخواسته خراب نکند.
- داده‌ها در سه فایل مستقل و مطابق schema نگهداری شوند.
- تغییرات همراه آزمون و به‌روزرسانی READMEها باشند؛ نتیجه CI یا آزمون دستی فقط در صورت اجرای واقعی گزارش شود.

## محدوده
این نقشه اکنون ادامه کار را از تکمیل داده به **اتصال، رفتار، دقت و آزمون runtime** هدایت می‌کند. هیچ اتصال یا رفتار runtime در مراحل تکمیل کاتالوگ ادعا نشده است.
