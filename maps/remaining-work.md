# نقشه جامع کارهای باقی‌مانده Editor1

این نقشه فقط کارهای تکمیل‌نشده را پوشش می‌دهد. تیک‌ها قابل کلیک‌اند و پیشرفت در همین مرورگر ذخیره می‌شود.

## اولویت ۱ — اتصال پیشنهادهای زنده به JSON
- [ ] بررسی نقاط اتصال فعلی موتور پیشنهادهای HTML، CSS و JavaScript
- [ ] اتصال پیشنهادهای runtime به سه فایل JSON و حذف منبع legacy فقط پس از اطمینان از برابری رفتار
- [ ] پیاده‌سازی Context Filtering: HTML (tag/attribute/parent-child)، CSS (selector/property/value) و JavaScript (scope/member/identifier)
- [ ] حفظ درج متن، Cursor و Selection؛ جلوگیری از درج تکراری
- [ ] کنترل کلیدهای Enter، Tab، Escape، Arrowها و رفتار IME فارسی
- [ ] کنترل Snippetها و اطمینان از غیرفعال بودن پیش‌فرض موارد ناخواسته

## اولویت ۲ — ممیزی و اصلاح پیشنهادها
- [ ] ممیزی کامل پیشنهاد تگ HTML و contextهای Parent/Child
- [ ] تطبیق context و پوشش رکوردها با استانداردها و منابع معتبر
- [ ] آزمون Undo/Redo، نمایش/فیلتر، درج، کلیدها و Duplicate
- [ ] ثبت ایرادها، اعمال اصلاحات و آزمون Regression

## اولویت ۳ — آزمون واقعی نسخه آفلاین
- [ ] آزمون در مرورگر دسکتاپ و موبایل با قطع اینترنت
- [ ] بررسی Console و هشدارهای import.meta.url
- [ ] آزمون Preview مربوط به CSS و JavaScript در حالت آفلاین
- [ ] آزمون Storage، بازیابی، Reset، تعویض تب‌ها، کلیدهای موبایل و Divider
- [ ] بررسی درخواست‌های شبکه و اطمینان از نبود وابستگی خارجی
- [ ] اصلاح ایرادها، اجرای مجدد Build و CI و ثبت نتایج واقعی

## اولویت ۴ — ابزار مدیریت کاتالوگ
- [ ] فرم ایجاد/ویرایش رکورد تکی
- [ ] واردکردن Excel و نگاشت ستون‌ها
- [ ] ورود گروهی با Copy/Paste
- [ ] جدول پیش‌نویس با ویرایش، حذف و تشخیص تکرار
- [ ] اعتبارسنجی Schema، داده ناقص و Duplicate و خروجی JSON
- [ ] انتشار امن GitHub با حداقل دسترسی، بررسی SHA و مدیریت Conflict
- [ ] آزمون ابزار مدیریت و سازگاری با Offline Build

## اولویت ۵ — کیفیت و سرعت
- [ ] تکمیل اعتبارسنجی جامع سه JSON پس از اتصال runtime
- [ ] بررسی صحت Metadata، Context، فعال/غیرفعال بودن و پوشش رکوردها
- [ ] اندازه‌گیری زمان پاسخ، Ranking و بهینه‌سازی عملکرد/Cache
- [ ] آزمون یکپارچه نهایی، Regression، CI و مرورگر
- [ ] به‌روزرسانی README و نقشه‌های مرتبط با نتایج واقعی
