# قانون معماری CSS — Editor1

این سند قانون رسمی و الزام‌آور پروژه برای ساخت، اصلاح و نگهداری CSS است.

## قانون ۱: یک منبع CSS

- **تمام کدهای CSS پروژه فقط در فایل اصلی `/style.css` در ریشه مخزن نگهداری می‌شوند.**
- ایجاد فایل CSS جدید برای هر جزء، صفحه، iframe، Web Component یا قابلیت ممنوع است.
- CSSهای موجود در پوشه‌های `core/` و `alfacode/` باید به‌تدریج حذف شوند و قواعدشان، پس از انتقال و بررسی، در `/style.css` ادغام شوند.
- فایل‌های CSS پشتیبان که فقط برای حفظ نسخه قبلی ساخته شده‌اند، آرشیو محسوب می‌شوند و نباید به‌عنوان منبع فعال استایل بارگذاری شوند.

## قانون ۲: المان‌های هم‌نوع، استایل مشترک

- المان‌هایی با نقش و ظاهر یکسان باید از کلاس‌ها و قواعد CSS مشترک استفاده کنند.
- برای هر دکمه، پنل، تب، ورودی، برچسب، popup یا عنصر مشابه، استایل مستقل و تکراری نسازید.
- تفاوت‌های لازم باید با modifier/class یا متغیرهای CSS روشن و محدود اعمال شوند، نه با کپی‌کردن کل بلوک استایل.
- قبل از اضافه کردن قانون جدید، `style.css` برای قانون مشترک موجود بررسی شود؛ قانون تکراری نسازید.

## قانون ۳: اجزای جدا و iframeها

- جدا بودن HTML یا JavaScript یک جزء به معنی مجاز بودن CSS جداگانه نیست.
- در صورت نیاز، همان فایل `/style.css` باید توسط صفحه یا iframe مربوط بارگذاری شود (با مسیر درست) یا به روش معتبر در دسترس قرار گیرد.
- استایل عناصر داخلی iframe از بیرون iframe قابل اعمال مستقیم نیست؛ باید stylesheet مرکزی در خود سند iframe بارگذاری شود.
- برای Shadow DOM، از ایجاد CSS جدا اجتناب شود؛ در صورت نیاز به استایل مرکزی، ساختار باید به Light DOM تغییر کند یا راهکار سازگار با منبع مرکزی پیاده شود.
- CSS برای صفحه‌های مستقل مانند کاتالوگ نیز باید در همین فایل مرکزی قرار گیرد و با selectorهای scoped از استایل بخش‌های دیگر جدا بماند.

## قانون ۴: نگهداری و آزمون

- هر تغییر ظاهری فقط در `/style.css` انجام شود.
- در هر تغییر، README و `maps/ROADMAP.md` به‌روز شوند.
- قبل از حذف CSS قدیمی، قواعد آن به CSS مرکزی منتقل، ارجاع/بارگذاری‌ها اصلاح، و تست‌های مرتبط اجرا شوند.
- پس از مهاجرت، فایل‌های CSS قدیمی (غیر از نسخه‌های پشتیبان آرشیوی) باید حذف شوند.
- معیار پذیرش: CSS فعال در پروژه فقط از `/style.css` تأمین شود؛ هیچ CSS فعال دیگری باقی نماند و المان‌های مشابه از استایل مشترک بهره ببرند.
